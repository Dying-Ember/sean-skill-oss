- 仓库：[Dying-Ember/sean-skill-oss](https://github.com/Dying-Ember/sean-skill-oss)，独立公开仓库。

- 入口：[skills/sean/SKILL.md](skills/sean/SKILL.md)。
- 安装单元：整个 `skills/sean` 目录，共 19 个文件。
- 运行依赖：读取本地文本的能力。静态校验需要 Python 3.9 或更高版本，只使用标准库。
- 许可证：[MIT](LICENSE)，版权归属为仓库作者 Dying-Ember。

## 保留了什么

保留用途与目标校准、问题处理步骤、学习与工具偏好，以及理解、证据、公平和责任的讨论。本次加入制度发生、评价与分配链条、二阶认同及制度再生产。它们是方法参考，不预设固定人格或唯一价值排名，也不自动属于当前使用者。

家庭信息、健康信息、欲望的具体形式和可识别私人经历不进入公开包。原始选引及消息、路径、时间和来源关系被整体替换，而非只给个别句子打码。详见 [隐私说明](PRIVACY.md)。

## 使用与安装

Skill 名称是 `sean`，文件入口是 `skills/sean/SKILL.md`。触发方式、安装位置和是否支持自动发现取决于当前宿主，不预设任何命令前缀或固定目录。

1. 先核实宿主支持的 skill 目录、发现机制与调用方式；使用它实际提供的安装入口。
2. 安装整个 `skills/sean` 目录，不只复制入口文件。没有可核实的注册机制时，将目录放到可持久读取的位置，并直接指定 `SKILL.md`。
3. 发现已有 `sean` 或旧名 `pwrm` 时先比较差异。相同则复用；升级前将旧版完整备份到自动发现目录之外，保留本地定制。不要把新旧文件混合。
4. 对照 `skill-manifest.json` 核对全部文件字节数与 SHA-256，确认入口和相对链接可读。
5. 使用宿主已验证的发现或调用机制；若只验证了文件读取，明确报告“文件入口可用”，不要声称已自动注册。

可直接交给安装者的要求：


调用语法由宿主决定。以下是普通语言请求示例，不是命令格式：

- 根据当前提供的立场写意见草稿，保留事实，不新增承诺。

## 更新与回退

仓库副本和安装目录可能是两份文件，更新前先检查本地差异。仅更新当前请求覆盖的内容，不强制覆盖定制。使用版本库时保留当前提交并检查未提交更改；安装时先备份完整旧目录，再放入经清单核对的新版。回退时恢复该备份，并按宿主的实际机制重新读取。

私人版与公开版使用同一入口名，不能在同一发现目录混装。公开包只允许纳入明确授权并完成脱敏复核的材料。

## 文件结构

- `skills/sean/SKILL.md`：唯一文件入口。
- `skills/sean/routes`：5 条任务路线。
- `skills/sean/references`：8 份主题及使用边界。
- `skills/sean/evidence`：36 条公开转述、5 个假设示例及资料边界。
- `skills/sean/LICENSE`：随安装目录保留的 MIT 许可证。
- `skill-manifest.json`：安装文件的字节数与 SHA-256。
- `release-manifest.json`：除自身外的全部发布文件清单。
- `scripts/validate.py`：离线静态校验，不联网、不收集用户数据。
- `tests/scenarios.json`：13 个行为试用场景，不等于自动模型测试。

按任务逐步加载，不必读取全部条目。维护规则见 [架构说明](skills/sean/ARCHITECTURE.md)。普通事实查询、翻译和机械编辑不需要个人认知分析；本版不提供历史原话，不能恢复被移除的私人信息。
