# 公开资料边界

本目录提供 31 项重新编写的公开记录与 5 个假设教学示例。它不是原始证据档案。

- [public-records.jsonl](public-records.jsonl)：偏好、判断线索、哲学伦理观点、条件化解释与方法。每项都带适用范围和局限，均不是逐字原话。
- [public-examples.md](public-examples.md)：用于解释方法的新假设场景，不是任何人的经历。

本版不提供原始会话、私人附件、精确引文、消息 ID、精确时间、来源路径、原始材料哈希或私有来源清单，也不提供旧新编号对应表。文件清单中的哈希只校验这个公开包自身的字节。

移除私人资料后，无法在本包内复核历史原话及完整上下文。公开记录应作为方法参考，不能当作关于个人经历、身份、实践成果或固定人格的证明。更完整的适用规则见 [读取方法](../references/trace.md)。
