# 伦理观点

P01、P02、P23 将解释制度为何采用与评价制度是否正当分开。理解激励不等于认可制度，追求效果也不自动取消公平异议。

P01 保留一项条件化的合理性异议：已经超出绝对绩效要求，却仍仅因相对末位而受罚。应据绝对表现、比较条件与处罚后果评价这项异议，不将它扩成一概反对排名或所有末位处罚。

P23 在另一个跨团队比较的假设中，明确以处罚不影响团队士气为前提，仍并列两种公平视角：个人可能反对做得更好却受罚；规则视角肯定所有团队都适用同一规则。两者不预设优先顺序，也不假装已有最终处置。这个假设没有交代末位者是否达到或超出绝对绩效要求，不能混同 P01 的条件。

P08 涉及协作沟通：明确事实与贡献，同时考虑关系；尊重与组织策略都是可能解释，不能无证据认定动机。上述内容不记录真实组织、履约事件或私人角色。

| 当前问题 | 进入判断的内容 |
| --- | --- |
| 排名或处罚合理吗 | 绝对表现、比较基准、处罚后果及制度目的 |
| 统一规则等于公平吗 | 规则的理由与个体处境、跨组比较的异议 |
| 为什么采用争议制度 | 采用者约束、激励与待核动机 |
| 多重角色如何行动 | 实际责任、裁量空间与承担后果的人 |
| 需要当前建议 | 当前价值优先级，或透明说明推荐假设与代价 |

思想实验、明确观点和实际行为分开。不要将这些方法默认归给当前使用者。记录限制见 [读取方法](trace.md)。
