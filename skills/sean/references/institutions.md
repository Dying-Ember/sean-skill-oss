# 制度发生与再生产

公开条目 P32 至 P36 为抽象转述，分别记录问题层次、评价与分配链条、二阶认同、层级差异假说及沟通修正。它们不记录真实组织、个人角色、具体事件或参与者信念。下列分析步骤是方法设计，不能反向认定为 Sean 的逐项原话，也不自动代表当前使用者的立场。

## 把问题留在所问层次

先辨认当前任务：制度怎样产生和维系，是发生学问题；制度带来什么净效果，是经验评价；制度是否正当，是规范评价。三者可以连接，但不要用后两者替换前者。用户已明确知道某项限定时，把真正影响解释的边界说一次，继续推演机制。

## 分析制度怎样被做出来

以下是把讨论转成可复用分析步骤的设计，不是逐项历史原话。

1. 找出组织必须处理什么：比较不同工作、分配稀缺机会、传导决定，还是追究责任。
2. 追踪判断如何转成共同分类：指标、排名和配额如何进入表格、校准、预算或正式评价；这些环节是待查候选，不预设每个组织都具备。
3. 沿角色链向上和向下看：谁评价别人，又因是否完成评价而被评价？资源、责任和裁量怎样经同一链条传导？
4. 区分相信、预期和行动：一个人相信规则，与他相信别人会遵守规则，是不同变量。再看偏离规则的代价怎样让不同信念的人继续参与。
5. 追踪再生产：上一轮形成的预算、分类、行为预期与责任安排，怎样变成下一轮必须面对的既定条件。惯性与意识形态可以在行动组织中相接，不必先限定为真心信仰。
6. 指出解释的关键分叉：取消配额、解除对管理者的连带评价或改变偏离代价后，机制会怎样变化？据此寻找最能区分解释的材料。

有外部查证需求时，找制度文件、参与者叙述、会议或组织研究，注明材料实际能支持哪一环。理论推演可以抽象，但制度起源、真实动机与总体效果需要对应证据。没有材料时提供工作解释，不用熟悉的理论名词冒充已完成调查。

## 二阶认同与层级假说

二阶机制不要求所有人不信，也不要求所有人都知道所有人的内心。只要有关参与者对他人的遵守与偏离成本形成足够稳定的预期，不同信念就可能汇合为一致行动。真心认同、策略遵守和工具性使用可以共存。

越接近制定或调配规则的位置，越可能以工具性方式理解它，是可检验的层级假说，不是层级职位自动决定心理状态的事实。应用时比较实际表述、裁量和行动，不代替他人断言内心。

## 回答方式

先给当前最有解释力的机制，再展开关键连接。保留真正有区分力的反例与未知项，避免每推进一步都重复“并非最优”。用户若转而问公平、效果或行动建议，再转入相应路线。
