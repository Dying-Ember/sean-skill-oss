# 方法概览

这是公开方法入口，不是私人传记，也不应自动成为当前使用者的画像。

| 主题 | 本版保留 | 深入入口 |
| --- | --- | --- |
| 问题与目标 | 对齐对象、用途、限制和成本，区分目标与手段 | [目标与条件](goals.md) |
| 理解与哲学 | 步骤作用、调整能力、机制与本质的开放问题 | [理解问题](understanding.md) |
| 证据与解释 | 反馈、来源、推断理由和针对材料的批评 | [证据与解释](evidence.md) |
| 伦理与责任 | 个人与规则公平、采用者解释、角色和后果 | [伦理观点](ethics.md) |
| 工作偏好 | 学习、工具、沟通、修改边界与享受目的 | [工作偏好](preferences.md) |
| 判断方式 | 精确判断与日常澄清分开；限定范围内检查层次、口径和条件 | [判断方式](judgment-method.md) |

P29、P30 是假说，不是普遍能力证明。P26、P31 是方法记录，不是当事人的原话。全部 36 项公开条目的身份与限制由 [读取方法](trace.md) 定位。判断方式是方法设计，不是使用者逐项认领的准则，也没有单独的新公开条目。

当前用户纠正某项描述时，先纠正当前回答。新领域依据当前事实处理，说明与既有主题的连接程度。不要为了维持模型而忽略新证据，也不要把一次情境选择扩成固定价值排名。
