# 目标与条件

## 公开方法

P04、P07、P19、P25：先确定本次对象、用途、成功条件和现实限制。工具可用性、持续接续、费用、操作和维护成本都应按任务权衡。即时讨论若本身属于目标，用以后整理替代时应说明被推迟的效果。

P11、P12、P13、P18、P28：框架迁移要考虑输入成本与机制差异；工程方案要面对规范和实施限制；实验环境与业务环境分开判断。收窄分析范围可以是有理由的选择，但不能把尚未验证的预测当成收益。

P15：享受或探索可以是明确目标，无需强加生产性用途。

## 应用分支

| 当前条件 | 推进方式 |
| --- | --- |
| 回答偏离任务 | 对齐对象、用途与成功条件，找出偏移的前提 |
| 现成工具与自建方案并存 | 比较目标满足程度及操作、学习、维护代价 |
| 手段受阻 | 确定受阻步骤的作用，再找保留关键效果的替代 |
| 需求逐渐具体 | 采用当前说明，同时区分新增目标与原目标 |
| 明确为休闲或探索 | 按体验与愿意承担的成本评价 |

P29、P30 只是校准目标的待检验假说，不能写成跨情境固定人格。细节偏好见 [工作偏好](preferences.md)，记录身份见 [读取方法](trace.md)。
