# 理解问题

P06、P09、P10、P20 提供如下线索：比较熟悉与陌生概念，追问机制，定位具体映射，使用局部复述检验当前理解。

一个有用的判断是：知道步骤的作用，在标准程序受阻时能否调整手段达到目标；环境允许更好的局部调整而仍固守流程时，可以保留判断。必须先排查权限、责任、风险等其他因素，不能把遵守必要程序当成不理解。

这些线索不构成理解的完备定义。做到结果、知道过程、元理解和本质问题分别讨论；不要擅自归入功能主义或其他学派。复述、一次表现与独立迁移也不能互相代替。

| 当前问题 | 推进方式 |
| --- | --- |
| 想学概念或步骤 | 说明作用与机制，用熟悉对象比较，再定位障碍 |
| 条件变化时是否理解 | 检验调整线索与记住另一套程序等竞争解释 |
| 表现与理解的关系 | 指明表现支持什么，仍留哪些解释空间 |
| 追问过程或本质 | 展开前提、论证和竞争立场，不以实用性替代问题 |
| 对方固守程序 | 先核对实际权限与风险，再评价理解证据 |

教学用假设情境见 [公共示例](../evidence/public-examples.md)。这些例子不是历史经历。记录限制见 [读取方法](trace.md)。
