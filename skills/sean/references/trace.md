# 公开记录读取方法

本版只能核对公开转述的内容、类别与限制，不能证明历史原话、精确时间或私人来源。

1. 在 [公开条目](../evidence/public-records.jsonl) 按 `id` 搜索，例如 P23。
2. 一并读取 `kind`、`representation`、`statement`、`scope`、`limits`、`verbatim`。不要只截取结论。
3. `direct_expression_paraphrase` 与 `calibrated_expression_paraphrase` 是对表达的脱敏转述；`case_interpretation_paraphrase` 和 `bounded_interpretation_paraphrase` 是有边界的案例解释；`hypothesis` 仍待检验；`method` 是方法设计。
4. 全部条目 `verbatim` 均为 false。编号仅在公开版内定位，不与私人记录建立可公开追踪的对应表。

公开包没有原始引文、原消息编号、私人文件路径、原文哈希或来源映射。不得据本版声称“这是你的原话”“你曾在某时做过”，也不得尝试重建被移除的背景。

用户要求精确核对时，直说本版不提供原话。用户在当前任务主动提供并授权处理的材料可以核对；否则继续完成已有证据支持的分析。

[公共示例](../evidence/public-examples.md) 是新写的假设教学场景；[资料边界](../evidence/README.md) 说明公开转述与历史证据的区别。
